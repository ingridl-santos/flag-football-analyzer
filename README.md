## Available Scripts
In the project directory, you can run all the commands below.

| Script                          | Description                                                                                                                                                                                                                                                                                                                                     |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `npm run dev`                 | Launches the app in development mode                                                                                                                                                                                                                                                         |
| `npm run build`                 | Builds the app for production to the `build` folder. It correctly bundles React in production mode and optimizes the build for the best performance, it is minified and the filenames include the hashes. [More information](https://create-react-app.dev/docs/deployment/)                                                                     |
| `npm run lint`                  | Checks code for style and quality issues                                                                                                                                                                                                                                                                                                        |
| `npm run test`                  | Runs tests and performs [Storybook Storyshot](https://storybook.js.org/addons/@storybook/addon-storyshots) tests. All stories are saved and compared against any changes, if the change was intentional, **UPDATE THEIR SNAPSHOTS**. See more information about [running tests](https://facebook.github.io/create-react-app/docs/running-tests) |
| `npm run test:update-snapshots` | Updates outdated component snapshots for testing. Use it if you have made intentional changes to components                                                                                                                                                                                                                                     |
| `npm run test:watch`            | Runs tests in interactive watch mode                                                                                                                                                                                                                                                                                                            |
| `npm run test:coverage`         | Calculates code coverage and outputs results to a `coverage` folder                                                                                                                                                                                                                                                                             |
| `npm run storybook`             | Uses Storybook to write stories for components at [http://localhost:6006](http://localhost:6006)                                                                                                                                                                                                                                                |
| `npm run storybook:build`       | Builds Storybook for production in the `storybook-static` folder
